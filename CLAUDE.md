# RULES
The project context is in the Word docs in the backend repo's docs folder (`../backend app/docs`), and the project timesheet is the Excel sheet in the same folder. Always refer to these for this project.

The API is the Django REST Framework backend in `../backend app` (runs on http://localhost:8000; Swagger at /v1/docs/). Keep the types in `src/lib/api.ts` in sync with its serializers.
